# Phase 5 — Cases UX

## Design intent

The Cases area is the operational register for investigations. The redesign prioritizes fast scanning, status-oriented triage, direct navigation and a clear distinction between the register and an individual investigation workspace.

## Redesigned areas

- Case register summary cards
- Search and status filtering
- Desktop case table
- Mobile case list
- Pagination controls
- New-case dialog
- Case workspace header
- Case workspace navigation
- Case overview introduction and intelligence snapshot

## Functional preservation

Existing API calls, route structure, permissions, case creation, status updates, archive behavior, member access and nested investigation routes remain unchanged.
