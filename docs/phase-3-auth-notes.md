# Phase 3 — Authentication UX

The authentication screens were redesigned around a focused, accessible government-service pattern: clear task hierarchy, short explanatory copy, explicit labels, visible password controls, inline validation, restrained institutional styling, and responsive layouts.

Research references used for the direction:
- US Web Design System sign-in guidance: concise sign-in, password visibility, accessible feedback, and easy switching between sign-in/create-account journeys.
- GOV.UK account-creation guidance: clear language, focused account creation, concise journeys, and explicit password requirements.

No authentication API, state-management, route, or business logic was changed.
